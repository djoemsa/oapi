# Summary: T-015 — Add/Edit Key Form (Huh)

**Timestamp:** 20260617_155200  
**Status:** Completed  

## What was done
Embedded `charmbracelet/huh` forms in the providers view to support inline addition and editing of API keys.

## Approach taken
- Integrated `huh.Form` inside `views.ProvidersModel`.
- Built fields: Select dropdown for Provider, text input for Model (validated non-empty), API Key input (validated non-empty and configured with EchoModePassword for masking during entry), and numeric input strings for RPM, RPD, and TPM (validated integer format).
- Pre-filled fields when editing existing keys by pressing `e`, and started with fresh defaults when adding via `a`.
- Saved the inputs atomically to `oapi.yaml` using `config.SaveConfig` and updated the thread-safe `KeyPool` in-memory representation.
- Rendered the form dynamically inside the right details pane when in `modeForm`.
