**Timestamp:** 20260617_151800

## What was done
Implemented the root Bubble Tea application structure supporting alternate screen buffer rendering, centralized Lipgloss styling, tab-switching navigation, and stub pages for downstream views.

- Built root `AppModel` handling global hotkeys (`q`, `ctrl+c` for graceful shutdown, `tab` / `]` and `shift+tab` / `[` for navigation).
- Created stub sub-models for Providers, Routes, and Logs views.
- Modified `cmd/root.go` to parse configs and state, and run the Bubble Tea TUI app.
