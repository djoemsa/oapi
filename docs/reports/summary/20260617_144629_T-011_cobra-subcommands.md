# Summary: T-011 — Cobra Subcommands

**Timestamp:** 20260617_144629
**Status:** Completed

## What was done
Implemented a command-line interface (CLI) for `oapi` using Cobra. Added persistent configuration and port override flags, CLI commands for serve (daemon mode), add-key (interactive terminal form), test-keys (connection checks), status (key pool metrics), config (YAML dump), logs (log tailing), and version. By default, running the program without arguments prints a placeholder indicating launching the Bubble Tea TUI.

## Approach taken
- Utilized `github.com/spf13/cobra` for command routing and persistent flag bindings.
- Utilized `github.com/charmbracelet/huh` to provide an interactive, masked, and validated inline form to add provider keys. Recommended models and provider IDs are populated from `internal/registry`.
- Configured double-logging inside `serve` to dual-write to stderr and `oapi.log` located inside the resolved config directory using `io.MultiWriter`.
- Avoided polling/tailing external dependencies by implementing a lightweight loop with file offset checks and rotation safety (reset offset on truncation) inside `logs` command.
- Addressed double-stop races on OS interrupt signals by wrapping `Stop()` inside `sync.Once` and coordinating with a `Stopped()` channel on the proxy server.
- Addressed security mandates by implementing `MaskAPIKey` to prevent secret key leakage in status, config, and test outputs.
